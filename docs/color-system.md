# Athishay.dev Color System

Version: 1.0

---

# Philosophy

The interface should never compete with the content.

The website exists to showcase products, ideas, and engineering—not decorative UI.

Colors should communicate hierarchy, interaction, and trust.

The projects should provide the visual richness.

The UI should remain calm.

---

# Brand Personality

- Engineering
- Minimal
- Premium
- Modern
- Reliable
- Calm
- Purposeful

---

# Theme Strategy

Engineering Light

Engineering Dark

Both themes should feel like the same product, not two different websites.

# Color Usage Rules

95% Neutral

4% Primary Blue

1% Accent

The UI should never become more colorful than the projects.

---

# Accessibility

Minimum AA Contrast

Never rely on color alone.

Always pair color with iconography or text.

Focus states must remain visible.

---

# Future

The system should support unlimited future themes while preserving the same visual language.
