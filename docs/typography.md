# Philosophy

Typography is the primary visual element.

The hierarchy should be created using spacing, weight, and scale—not excessive color.

The website should remain highly readable across desktop, tablet, and mobile.

# Typography Rules

Never use more than three font families.

Never use text shadows.

Avoid all caps for long text.

Use bold for emphasis instead of color.

Maintain consistent spacing between headings and paragraphs.

---

# Accessibility

Minimum body size: 16px

Minimum contrast: WCAG AA

Line height should always improve readability over compactness.
