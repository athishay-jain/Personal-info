# Philosophy

Icons should support content.

Never replace content.

Icons should communicate faster, not decorate.

# Accessibility

---

# Design Rules

Icons are secondary.

Typography is primary.

Images are stronger than icons.

Icons should never become the visual focus of the page.

Good icon usage is almost invisible.
