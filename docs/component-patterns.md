# Athishay.dev Component Patterns

Version: 1.0

---

# Philosophy

Patterns are combinations of components that solve recurring user problems.

Components answer:

"How should this element look?"

Patterns answer:

"How should this experience work?"

Patterns should remain consistent across the entire website.

---

###########################################################
# HERO PATTERN
###########################################################

Purpose

Introduce the page immediately.

Structure

Eyebrow

↓

Heading

↓

Description

↓

Primary CTA

↓

Secondary CTA

↓

Statistics

↓

Visual

Rules

One H1 only.

Maximum two CTAs.

Maximum four statistics.

Never exceed four lines of heading.

Visual occupies 40–50% width.

# Pattern Rules

Every pattern should:

Be reusable.

Support mobile.

Support dark mode.

Support keyboard navigation.

Support accessibility.

Support future expansion.

Never require redesign when adding new content.
