# Project Description

Dynamic IoT is a free platform that simplifies connecting ESP32, ESP8266, and NodeMCU-based hardware to a mobile application without requiring users to manually configure Wi-Fi settings or build a custom mobile app for every project.

The platform allows developers, students, and makers to create fully customizable dashboards through a web interface. Each device is assigned a unique UID, and the mobile app automatically discovers and connects to the hardware over a local Wi-Fi Access Point while allowing users to keep their internet connection active.

The goal is to make IoT hardware setup simple, scalable, and accessible for everyone.

---

# Problem Statement

While teaching and developing IoT projects for students, I noticed that many struggled with:

- Configuring Wi-Fi credentials.
- Accessing hardware configuration pages.
- Updating UI labels and controls.
- Creating a separate mobile app for every project.
- Managing multiple IoT devices.

Dynamic IoT was created to eliminate these repetitive tasks by providing a reusable IoT platform.

---

# Solution

Instead of writing a new application for every hardware project, users simply:

1. Create a device in the dashboard.
2. Generate a unique Device UID.
3. Configure widgets and endpoints.
4. Download the Dynamic IoT mobile app.
5. Enter the Device UID.
6. Instantly control the hardware.

Any changes made in the dashboard automatically appear inside the mobile application without rebuilding the app.
